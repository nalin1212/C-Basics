# Principle (Programming Principles)

These are the fundamental ideas that help you write clean, efficient, and maintainable code.
*Important Principles*
1.*DRY (Don't Repeat Yourself)* – Avoid duplicate code.
2.*KISS (Keep It Simple, Stupid)* – Prefer simple solutions.
3.*YAGNI (You Aren't Gonna Need It)* – Don't add features until they're needed.
4.*Modularity* – Break code into small functions/classes.
5.*Abstraction* – Hide unnecessary implementation details.
6.*Encapsulation* – Keep data and methods together.
7.*Time & Space Complexity* – Always think about algorithm efficiency.
